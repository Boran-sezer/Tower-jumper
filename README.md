# ⬛ TOWER JUMPER ⬛

**Tower Jumper** est un jeu d'arcade minimaliste et addictif développé en HTML5 Canvas et JavaScript pur. Le but est simple : empiler des blocs pour construire la tour la plus haute possible sans tomber ! 🏗️

## 🎮 Aperçu du Jeu

Le jeu s'adapte à toutes les tailles d'écran (Responsive) et propose un mode plein écran pour une immersion totale. 🌌

### Fonctionnalités :
*   **Physique de saut** : Gravité et inertie pour un ressenti arcade.
*   **Difficulté progressive** : La vitesse des blocs augmente à mesure que votre score grimpe.
*   **Système de vies** : Vous avez 3 chances avant le Game Over. 💔
*   **Design Pixel Art** : Un style rétro avec des ombres dynamiques.
*   **Support Mobile** : Jouable au clavier (Espace/Haut) ou via le tactile.

---

## 🕹️ Comment Jouer ?

1.  Lancez le jeu.
2.  Cliquez sur le bouton **"PLEIN ÉCRAN"** pour une meilleure expérience. ⛶
3.  Attendez que le bloc mobile passe au-dessus de votre tour.
4.  **Sautez** au bon moment pour atterrir dessus !
5.  Si vous ratez le bloc, vous perdez une vie. À zéro, c'est fini.

**Commandes :**
*   **PC** : Barre Espace ou Flèche Haut.
*   **Mobile / Tablette** : Appuyez n'importe où sur l'écran.
